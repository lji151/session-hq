# Decision log

One line per decision the user actually made, appended, newest at the bottom. Format:

```
- YYYY-MM-DD | what was decided | domain
```

Record the decision, not the discussion. If a decision reverses an earlier one, add a new line
saying so — never edit or delete the old line. The value of this file is that it is honest
about the order things happened in.
